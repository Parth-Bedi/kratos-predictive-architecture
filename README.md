# The Kratos Predictive Architecture

This repository contains the official 10,000-run simulation code for the **Kratos Predictive Architecture**, a proposed mathematical optimization model for quantifying post-flow cognitive adaptation thresholds.

The Python engine evaluates the core equations of the framework, calculating cognitive baseline expansion from acute neural friction. It utilizes a Linear Proximity Dynamic Brake to enforce asymptotic convergence toward a physical limit of 200 Kr, preventing runaway mathematical inversion.

**Repository Contents**
* `kratos_engine.py`: The core Python simulation engine and 10,000-cohort data generator.
* `kratos_architecture_final_version1.pdf`: The original research paper detailing the mathematical bounds, governing formulas, and theoretical constraints.
* `kratos_10k_unconstrained_runs.csv`: The output dataset automatically generated by running the script.

**How to Run the Simulation**
1. Clone this repository to your local machine.
2. Install the required mathematical dependencies: `pip install -r requirements.txt`
3. Execute the script: `python kratos_engine.py`
